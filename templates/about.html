About the Project

This Movie Recommendation System is a full-stack web application designed to recommend movies based on a user's tastes. It uses machine learning algorithms to compute similarity between movies based on their metadata (genres and plot summaries).

How It Works

The system utilizes Content-Based Filtering, a recommendation strategy where the system makes recommendations based on the item's properties (content) rather than user behaviors (collaborative filtering).

  • Text Feature Extraction: The genres and overview text for each movie are combined to create a rich description of the movie's content.
  • TF-IDF Vectorization: The Term Frequency-Inverse Document Frequency (TF-IDF) Vectorizer translates this text content into a mathematical vector representation, representing the importance of words relative to the entire dataset.
  • Cosine Similarity: Pairwise similarity scores are calculated between all movie vectors. Cosine similarity calculates the cosine of the angle between two multi-dimensional vectors, yielding a score between 0 (completely different) and 1 (identical).
  • Retrieval: When you search a movie, the system queries the similarity matrix, extracts the top 10 movies with the highest similarity scores, and presents them sorted by match percentage.

Technology Stack

Python Flask

Web framework powering the backend routes and serving templates.

Pandas & NumPy

Data science libraries used for loading, cleaning, and indexing CSV datasets.

Scikit-Learn

Machine learning library supplying TF-IDF Vectorizer and Cosine Similarity.

HTML, CSS & JS

Clean vanilla styling with micro-animations and AJAX autocomplete features.

Key Features

  • Content-based text filtering using TF-IDF and Cosine Similarity.
  • Search autocomplete with real-time suggestion list fed by backend API.
  • Responsive card layout displaying movie posters, titles, genres, ratings, and release years.
  • Visual loading spinner during page transitions.
  • Robust poster fallback logic that generates beautiful custom SVG/CSS placeholders if image loading fails.
